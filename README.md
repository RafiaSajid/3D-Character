# **3D-Character**



### Description:



A low-poly 3D character with idle(breathing),jump, and run animations.



#### Materials:

There are 3 materials made:

* Skin.
* Pant.
* Shirt(eyes, and shoes).



##### Notes:

It was made for a Unreal game project (Eat Right Run).

It also consist of a duplicate character with armature (no animations).
